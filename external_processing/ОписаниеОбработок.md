# Внешние обработки (.epf)

В проект входят две внешние обработки, облегчающие работу с интеграцией. Они не включены в основную конфигурацию (исходный код в `.bsl` файлах), но могут быть собраны в `.epf` для использования в режиме предприятия.

## 1. ПроверкаАвтозакрытияЗаказов
**Назначение:** Безопасное тестирование регламентного задания автозакрытия.
**Функции:**
*   Поиск заказов с нулевым остатком (сухой прогон).
*   Просмотр списка «зависших» заказов (>30 дней без отгрузок).
*   Выборочное закрытие заказов (создание документа `ЗакрытиеЗаказовПокупателей`).
*   Отправка тестового письма для проверки учетной записи почты.

## 2. МассоваяСинхронизацияБитрикс24
**Назначение:** Первичное заполнение базы Bitrix24 историческими данными из 1С.
**Функции:**
*   Выбор периода (даты начала и окончания).
*   Пакетная обработка документов `ЗаказПокупателя`, `ЗаказНаПроизводство`, `Реализация` за выбранный период.
*   Вывод подробного лога в форму без прерывания процесса при ошибках.
