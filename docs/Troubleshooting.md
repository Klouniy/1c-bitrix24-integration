# Решенные технические проблемы в ходе интеграции

В процессе разработки были выявлены и устранены следующие нетривиальные ошибки:

1. **Ошибка `Передача с клиента на сервер мутабельного значения`**
   * **Причина:** Попытка записи реквизита в типовой справочник `Пользователи` из подписки на событие.
   * **Решение:** Отказ от изменения типовых метаданных. Создан регистр сведений `СоответствиеИДБитрикс24` для кэширования ID.

2. **Все контрагенты привязывались к одной компании (ID=7)**
   * **Причина:** REST API Bitrix24 при поиске по `XML_ID` возвращал полный список компаний (игнорировал фильтр). Код брал первый попавшийся элемент.
   * **Решение:** Внедрена функция с перебором массива и строгой проверкой на точное совпадение по `TITLE`. Поиск по `XML_ID` упразднен.

3. **Ошибка `Could not find value for parameter {fields}`**
   * **Причина:** Неверный формат передачи параметров для метода `catalog.section.add`.
   * **Решение:** Параметры API были обернуты в структуру `fields`.

4. **Ошибка `Не указан поставщик` при проведении Прихода**
   * **Причина:** Для `docType = 'A'` Bitrix24 требует привязки CRM-сущности.
   * **Решение:** Смена типа документа на `Оприходование` (`docType = 'S'`) или добавление вызова `catalog.documentcontractor.add`.
